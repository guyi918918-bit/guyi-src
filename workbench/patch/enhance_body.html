用于隔离数据。所有设备必须填写完全相同的空间 ID，才能互相同步。
📖 还没有 Supabase？点这里看 5 步配置指引
  1. 打开 supabase.com → Start your project → 用 GitHub 或邮箱注册（免费）。
  2. New project → 填项目名、设置数据库密码 → 地区建议选 Southeast Asia (Singapore) → Create。等待约 2 分钟。
  3. 左侧 SQL Editor → New query → 粘贴下方建表 SQL → 点 Run。
  4. 左侧 Project Settings → Data API，复制 Project URL 和 anon public 密钥。
  5. 粘贴回上面两个输入框，自定义一个空间 ID，点「保存并连接」。其他设备打开同一网址、填相同的三项即可同步。
建表 SQL
create table if not exists public.wb_kv ( space text not null, k text not null, v jsonb not null, updated_at timestamptz not null default now(), primary key (space, k) ); alter table public.wb_kv enable row level security; drop policy if exists "wb_kv_anon_all" on public.wb_kv; create policy "wb_kv_anon_all" on public.wb_kv for all to anon using (true) with check (true); -- ✅ 上面三段一次粘贴运行即可。若运行后仍报错 PGRST125，再单独执行下面这句刷新缓存（一般无需）： -- NOTIFY pgrst, 'reload schema'; -- 验证：返回表名说明建表成功 select to_regclass('public.wb_kv');
注意：该策略允许持有 anon key 的人读写此表。空间 ID 相当于你的私人命名空间，请勿把 URL + key + 空间 ID 同时公开。
常见坑：建表 SQL 一定要在「你填的 Project URL 所属项目」里运行；若表已存在却仍报 PGRST125，执行上面的 NOTIFY pgrst 刷新缓存即可。
