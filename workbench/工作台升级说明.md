# 工作台 V2 升级说明（商机雷达 + 案例智库）

基于你《升级需求规格》与《四川政企招投标搜集工作文案》，本次在**原有工作台基础上纯增量**新增两个模块，界面更聚焦、内容更丰富，全部数据自动保存 + 跨设备云同步。

> 关于"自动推送外部标讯"：你明确要求"不要授权/花钱的功能，只用大众能搜到的"。所以外部信息采用**「一键深搜 + 本地自动沉淀」**方案——系统把各免费官方源/案例平台做成预填关键词的深搜入口，你每天点开 30 秒/源，系统负责归类、去重、生成客户画像与灵感早报。完全免费、合规，比硬上爬虫稳。

## 新增模块一：📡 商机雷达（拓客核心）
1. **一键深搜**：7 个来源卡片（四川省政府采购网、公共资源交易信息网、天府阳光采购、蜀道集采、中国招标投标公共服务平台、四川招标网、百度通用）。输入关键词（默认"活动 赛事 团建"），点"搜这个词"直接打开百度 site 检索结果页。
2. **订阅关键词库**：内置你文档里的 27 个标准检索词，可编辑/复制/一键生成"四川 XX 招标 采购 活动"检索句式。
3. **每日巡检清单**：对照你文档的"每日固定工作流程"，6 个必刷源勾选打卡，每日 0 点自动重置，显示"今日已巡检 N/6"。
4. **商机台账**：搜到的标讯在此结构化沉淀（单位/项目/类型/预算/截止/对接人/状态/来源链接），支持筛选、改状态、编辑、删除、导出 CSV。**自动接入云同步**。
5. **客户采购画像**：从台账自动统计——谁在持续买活动、买什么类型、花多少预算、最近时间。点单位名可反查其全部商机。

## 新增模块二：💡 案例智库（写方案提速）
1. **一键深搜案例平台**：数英网 / 广告门 / 活动行 / 梅花网 / Topys + 百度通用，预填词直达。
2. **本地案例库**：看到的优秀案例打标签沉淀（类型/行业/预算/亮点/标签/链接），支持筛选与检索。**自动接入云同步**。
3. **场景化智能推荐**：选"我正在做的项目类型"或输入自由描述，自动从案例库匹配同类优秀案例。
4. **灵感早报**：从你的案例库自动汇总——总数、类型分布柱状图、最近存入、今日随机灵感。每天点一下就有输入。

## 原有功能不变
日报/周报/月报/项目管理/客户/看板/年度/历史/回收站 + 云端同步（🟢已连接/🔴未连接）+ 草稿自动保存 + 历史折叠，全部原样保留，代码零删改。

## 使用建议（落地你的文档流程）
- **早 8 点**：打开「商机雷达」→ 点"全部渠道搜这个词"或在各官方源卡片点"搜这个词" → 把有价值标讯「➕ 新增商机」沉淀进台账 → 勾掉当日巡检。
- **写方案前**：打开「案例智库」→ 在场景化推荐选对应类型，调出同类案例找灵感 → 看到好案例随手「➕ 新增案例」。
- **每周**：案例库攒够后，点"生成灵感早报"做客户沟通话题储备。
